# Daily Work

## نبذة عن المشروع

**Daily Work** هو نظام ويب لإدارة وتنظيم المهام اليومية، يساعد المستخدم على إضافة مهامه وترتيب أولوياتها ومتابعة حالتها ونسبة الإنجاز بطريقة بسيطة وسهلة.

## المشكلة التي يعالجها

يساعد المشروع المستخدمين على تنظيم مهامهم اليومية بدل الاعتماد على التذكر أو الطرق التقليدية، من خلال جمع المهام في مكان واحد مع إمكانية متابعة التقدم والإنجاز.

## الفئة المستهدفة

* الطلاب
* الموظفون
* الأشخاص الذين يحتاجون إلى تنظيم مهامهم اليومية

## أهم وظائف المشروع

* إنشاء حساب وتسجيل الدخول
* إضافة المهام وتعديلها وحذفها
* تحديد أولوية المهمة
* تحديد حالة المهمة
* تحديد تاريخ الاستحقاق
* البحث عن المهام وترتيبها
* عرض نسبة إنجاز المهام
* لوحة تحكم لمتابعة المهام والإحصائيات
* إدارة الملف الشخصي
* تغيير كلمة المرور
* حذف الحساب

## التقنيات المستخدمة

* Laravel 12
* PHP 8.2
* MySQL / MariaDB
* Blade
* Tailwind CSS
* JavaScript
* Vite
* Git & GitHub
